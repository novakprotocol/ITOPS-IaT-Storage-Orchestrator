Draft enable/disable

The public console can draft an enable/disable change. The private control repository commit is the authority.

{
  "change_type": "job-enabled-state",
  "job_id": "example-daily-inventory",
  "old_enabled": false,
  "new_enabled": true,
  "requires_review": true,
  "requires_private_control_repo_commit": true
}

Scripts

Public examples are Python-only and non-operational. Real scripts belong in the private control repository and remain disabled until reviewed.

Approvals and SHA evidence

Enablement requires a private control-repository commit, reviewer, approver, release SHA, and rollback reference.
